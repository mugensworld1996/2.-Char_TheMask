# The Mask (1994) | MUGEN Project

## Sobre este proyecto

Este proyecto busca recrear a The Mask, el icónico personaje de la película de 1994, como
un personaje completamente jugable para MUGEN.

El objetivo es representar el estilo exagerado y caricaturesco del personaje, combinando
sus expresiones, humor, transformaciones y movimientos imposibles con un sistema de 
combate dinámico propio de MUGEN.

Actualmente el personaje se encuentra en una etapa temprana de desarrollo.

===============================================================================
1. SOBRE ESTE PROYECTO
===============================================================================

Personaje:
    The Mask / La Máscara

Origen / referencia:
    The Mask (película de 1994 / Dark Horse)

Estado:
    Desarrollo inicial / preproducción.

Este proyecto busca convertir a The Mask en un personaje jugable para MUGEN 1.0,
con sprites nuevos, animaciones propias y un gameplay diseñado alrededor de su
identidad.

ACLARACIÓN:
El archivo original de referencia de SNES es un char distinto, atribuido en su
DEF a Juan Carlos (VersionDate y MugenVersion: 11,29,2000). NO es el proyecto
nuevo ni se presentará su código como propio. Se estudia como antecedente.

===============================================================================
2. FILOSOFÍA
===============================================================================

El proyecto sigue la filosofía comunitaria usada en los demás chars de
Mugen's World:

    MUGEN es de la comunidad para la comunidad.

Los recursos creados específicamente para este proyecto se preparan con intención
de estudio, modificación y reutilización comunitaria, respetando siempre los
derechos de los propietarios de los personajes y franquicias originales.

Proyecto fan-made y sin fines comerciales.

===============================================================================
3. PIPELINE VISUAL
===============================================================================

Pipeline general previsto:

1. Crear / seleccionar imagen base.
2. Generar o adaptar apariencia 3D.
3. Crear animaciones.
4. Convertir a video cuando corresponda.
5. Extraer frames.
6. Limpiar manualmente.
7. Reescalar al tamaño objetivo del proyecto.
8. Preparar transparencia / BMP / palette.
9. Importar al SFF.
10. Crear AIR, CLSN y lógica MUGEN.

IMPORTANTE:
Los archivos originales de alta resolución deben conservarse separados de los
sprites finales reescalados.
