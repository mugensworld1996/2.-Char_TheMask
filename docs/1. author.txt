# The Mask (1994) | MUGEN Project

## Sobre este proyecto

Este proyecto busca recrear a The Mask, el icónico personaje de la película de 1994, como un personaje completamente jugable para MUGEN.

El objetivo es representar el estilo exagerado y caricaturesco del personaje, combinando sus expresiones, humor, transformaciones y movimientos imposibles con un sistema de combate dinámico propio de MUGEN.

Actualmente el personaje se encuentra en una etapa temprana de desarrollo.

## Filosofía del proyecto

Este proyecto sigue la filosofía clásica de la comunidad MUGEN:

> MUGEN es de la comunidad para la comunidad.

Todo el contenido aquí presente es completamente libre:

- Libre para usar
- Libre para modificar
- Libre para estudiar
- Libre para redistribuir

No existen:
- Paywalls
- Bloqueos
- Monetización
- Restricciones comunitarias

El objetivo es compartir conocimiento, recursos y contenido con la comunidad.

## Desarrollo del personaje

Los sprites de este personaje están siendo creados desde cero utilizando distintas herramientas de IA y procesos manuales de edición.

### Pipeline de desarrollo

1. Creación de sprites base
2. Conversión a estilo 3D
3. Generación de animaciones
4. Conversión a video
5. Extracción de frames
6. Conversión final a BMP para MUGEN

### Herramientas utilizadas

- ChatGPT
- Grok
- Gemini
- A2E
- Vidu
- VLC
- Fighter Factory Clasic

## Base del proyecto

El personaje está siendo desarrollado utilizando una base de código ya existente de MUGEN para agilizar la implementación de estados, física y comportamiento general.

Sobre esa base se están creando desde cero:

- Nuevos sprites
- Nuevas animaciones
- Sistema de ataques
- Efectos visuales
- Sonidos
- Mecánicas propias del personaje
- Expresiones faciales
- Variantes futuras
